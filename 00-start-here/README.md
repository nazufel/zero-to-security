# Module 0: Start Here

## Why this module matters

Before you touch Linux or the cloud, you need three things: a clear idea of the job you're aiming for, a place to show your work, and the habits that keep you out of trouble. This module is short. Don't skip it.

## You're ready to move on when…

- [ ] You can name the three target jobs and what each does on a normal day
- [ ] You know what you're allowed to scan and test, and what you're not
- [ ] You have a public GitHub portfolio repo with a README you wrote
- [ ] You can `add`, `commit`, and `push` from the command line without looking it up
- [ ] You can write a ticket someone else could act on without asking you a question
- [ ] You have a plan for what to do when you're stuck
